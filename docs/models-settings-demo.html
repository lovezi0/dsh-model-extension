可交互 Demo —— 使用说明（点击展开 / 收起） 界面为插件自写（样式 token 与类名沿用官方设计）；保存管线 vendor 自官方 ui-settings-models（store / operations / schema-operations）。
「供应商」页（Tabs）：显示名称（所有 pi-ai 路由，内置路由也可配——route key 不能改，displayName 是内置路由唯一的改名手段）· API 密钥 · API 地址 · API 协议（仅手声明路由）。　 「模型」页：模型目录，条目展开区为一块扩展面板（快速装入 / 容量 / 输入模态 / developer 角色 / 推理开关+挡位 / 其他兼容开关），无标题。
两级展开：点「编辑」展开编辑卡 → 编辑卡内是 Tabs 标签页（供应商 / 模型，默认停在「供应商」，切页不丢状态）→ 在「模型」页再点条目的「容量」箭头展开扩展区。
标题行：「模型+」+ 「下载/更新元数据」按钮——只服务 models.dev 源（下载并缓存到 DSH home）；llm-pi-ai 源运行时直读宿主已装目录，无需下载。官方「模型」页已通过 bundle patch 禁用，本页为唯一模型设置页。
「快速装入」＝三级收窄选择器 [数据源 ▼][提供方 ▼][model id]：数据源 llm-pi-ai（默认）/ models.dev；同一模型 id 横跨多个提供方（如 glm-5.3-flash 同时在 zai / baseten / together…），先选提供方再搜 id。提供方与 model id 的候选均为插件自绘浮层（datalist 的弹层位置与样式页面控制不了，已弃用）；上限 50 条，超出提示「另有 N 项匹配」。选完提供方自动聚焦 model id 框；选中后输入框保留该 id（同族模型的继续搜索起点）。
预填语义：容量 / 模态 / 挡位 / compat 整份替换（切换数据源后重选＝干净重写，不残留另一源的字段）；模型 ID 与显示名称只填空行、绝不覆盖已填值（目录 id 是官方端点的请求 id，走网关时上线字符串常常不同）。pi-ai 源：thinkingLevelMap → reasoningEfforts 按映射转换（null 两侧语义相反：目录里 null=不支持，行里 null=支持但不发送），compat 只写被 offer 的键，其余开关进「其他兼容开关」（清空即移除、回到目录默认）；models.dev 源：清空推理挡位与 compat，只留 supportsReasoningEffort。
推理区显隐：总开关 或 已声明挡位 或 已设思考格式，任一为真即显示——pi-ai 预填常常不写开关（交由适配器按 baseURL 检测），但挡位照样可编辑；此时开关下有灰字提示。取消「端点接受推理挡位参数」→ 挡位与思考格式一并清除且整块隐藏（不留孤儿参数）。「允许以 developer 角色发送系统提示」与「输入模态」不受它控制。
新模型行默认值（v1.0.0）：推理挡位开启且七档全声明、思考格式 openai、输入模态全选、developer 角色继承勾选。「获取可用模型」拉候选 → 「删除」走确认弹窗。
本 Demo 内置示例数据代替真实目录（pi-ai：6 个提供方，含 glm-5.3-flash 的多提供方重名、off:"none" 拼写、无 levelMap、anthropic 协议兜底；models.dev：4 条）。
