可交互 Demo　界面为插件自写（样式 token 与类名沿用官方设计）；保存管线 vendor 自官方 ui-settings-models @0.1.2-rc.1（store / operations / schema-operations）。
「供应商」页（Tabs）：API 密钥 · API 地址 · 显示名称 / API 协议（仅自定义路由）。　 「模型」页：模型目录，条目展开区为一块扩展面板（容量 / 输入模态 / developer 角色 / 推理挡位 / 思考格式 / 快速装入），无标题。
两级展开：点「编辑」展开编辑卡 → 编辑卡内是 Tabs 标签页（供应商 / 模型，默认停在「供应商」，切页不丢状态）→ 在「模型」页再点条目的「容量」箭头展开扩展区。
标题行：「模型+」+ 「下载/更新元数据」按钮（本 Demo 内为模拟；真实实现为点击后从 models.dev 下载并缓存到 DSH home，未就绪时快速装入提示不可用）。官方「模型」页已通过 bundle patch 禁用，本页为唯一模型设置页。
另可试：取消「端点接受推理挡位参数」→ 思考格式与推理挡位整块隐藏（且落盘时一并清除，不留孤儿参数）； 「允许以 developer 角色发送系统提示」与「输入模态」不受它控制 → 「获取可用模型」拉候选 → 「删除」走确认弹窗。
新模型行默认值（v1.0.0）：推理挡位开启且七档全声明、思考格式 openai、输入模态全选、developer 角色继承勾选。
「快速装入」：展开区顶部的可搜索下拉——只显示模型 id、忽略大小写模糊匹配、最多 10 条候选；真实数据源为 models.dev（本 Demo 用内置示例数据代替）。
